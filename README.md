# Shipping-code skills for Claude Code

Five skills that split feature work into stages with clean context and durable artifacts, instead of
one long chat that slowly forgets what you asked for.

| Skill | Job |
|---|---|
| `/create-td` | Requirements → technical design doc. Touches no code. |
| `/dev` | Tech doc → verified task breakdown → implementation |
| `/test` | Tests written against the spec, not the implementation |
| `/handoff` | Logical commits + a PR description worth reading |
| `/prototype` | Throwaway branch that answers "can this even be built?" |

Install and full write-up below — coming together as the skills land.

Based on [Agentic Workflow for Shipping Code](https://chaiilabs.com/blog/agentic-workflow-for-shipping-code).
