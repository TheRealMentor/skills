# Plain-word swaps and filler phrases

Use these as a guide, not a find-and-replace. Check that the plain word keeps the meaning in context.

## Word swaps

| Instead of | Use |
|---|---|
| utilize, leverage (verb) | use |
| commence, initiate | start, begin |
| terminate | stop, end |
| facilitate | help, allow |
| endeavor, attempt | try |
| ascertain | find out, check |
| demonstrate | show |
| subsequently | then, later |
| prior to | before |
| in order to | to |
| in the event that | if |
| with regard to, regarding | about |
| due to the fact that | because |
| at this point in time | now |
| a number of | several (or the exact number) |
| in close proximity to | near |
| sufficient | enough |
| require (when "need" works) | need |
| obtain | get |
| purchase | buy |
| modify | change |
| indicate | show, say |
| ensure | make sure |
| assist | help |
| numerous | many |
| approximately | about |
| additional | more, extra |
| methodology | method |
| functionality | feature, function |
| robust, seamless, cutting-edge | say what it does: "handles 10k requests per second" |

## Noun phrase to verb

| Instead of | Use |
|---|---|
| make a decision | decide |
| give consideration to | consider |
| perform an analysis of | analyze |
| carry out an installation of | install |
| provide an explanation of | explain |
| conduct a review of | review |
| is in agreement with | agrees with |
| has the ability to | can |

## Filler to cut

- "It is important to note that" / "It should be noted that" → say the thing.
- "Please be advised that" → say the thing.
- "As a matter of fact", "Needless to say", "At the end of the day"
- "In today's fast-paced world", "In the ever-evolving landscape of"
- "I hope this email finds you well" (keep for a first contact if the culture expects it)
- "Let's dive in", "Let's delve into", "Without further ado"
- "In conclusion", "To summarize" when the text is short
- "very", "really", "quite", "essentially", "basically", "simply", "just" (when used as filler)
- "Feel free to", "Don't hesitate to" → "Ask me if..." or just the request

## Idioms that confuse non-native readers

| Instead of | Use |
|---|---|
| touch base | talk, meet |
| circle back | return to, follow up |
| low-hanging fruit | easy wins |
| move the needle | have a clear effect |
| bandwidth (for time) | time, capacity |
| deep dive | detailed review |
| ballpark | rough estimate |
| out of the box | by default |
| heads up | warning, notice |
| ping me | message me |
| hit the ground running | start fast |
| on the same page | agree |

## Ambiguous words to watch

- **may / might**: permission or chance? Use "can" (ability), "is allowed to" (permission), "could" (chance).
- **should**: advice or requirement? Use "must" for requirements.
- **once**: "once the build ends" (when) vs "once" (one time). Use "after" or "one time".
- **since**: time or reason? Use "because" for reason, "after" or "from" for time.
- **while**: time or contrast? Use "but" or "although" for contrast.
- **this / that / it** at the start of a sentence with no clear noun. Repeat the noun.
